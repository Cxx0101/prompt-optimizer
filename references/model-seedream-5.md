# Seedream 5.0 Adapter

用于 Seedream 5.0 系列的文生图、参考图生图、图片编辑与组图生成。

## 写法

使用简洁、连贯、具体的自然语言。推荐顺序：

```text
图片用途 + 主体与行为 + 环境与空间关系 + 风格 / 色彩 / 光影 / 构图 + 参考素材角色 + 保留与禁止项
```

Seedream 5.0 能理解复杂意图和参考图关系，不要用重复华丽词汇覆盖其推理空间。对于常识或知识型画面，写清准确事实、可视化形式、目标受众与版式目标。

## 参考图生图

直接使用图号描述操作：

```text
以图 1 的人物为唯一主体外观参考；采用图 2 的正面构图和留白；仅参考图 3 的低饱和暖灰色调与柔和侧光。生成……
```

主体、风格、构图、产品和文字来源要分开。参考图很多时，只保留真正影响结果的素材。

## 图片编辑

使用短而明确的操作指令：

```text
仅将图 1 中 <对象> 改为 <目标>，保持 <动作 / 身份 / 构图 / 背景 / 文字> 不变。新内容自然匹配原图的透视、光线、阴影和材质。
```

需要参考另一张图时明确方向，例如：

- “将图 1 的色调调整为图 2 的色调”；
- “让图 1 的人物穿上图 2 的服装”；
- “参考图 2 的风格转换图 1，保留图 1 的构图与主体身份”。

如果素材带有箭头、线框或涂鸦，先判断它们是否是区域控制信号；只有确认后，才在 Prompt 中说明对标记区域执行修改。

## 组图

用户需要连续分镜、漫画或套系设计时，明确：

- 图片数量；
- 每张内容；
- 共同不变量；
- 每张允许变化的部分；
- 排列顺序或系列关系。

可使用“一组 / 一系列 / 共 N 张”表达。不要让每张图重新设计角色或产品。

## 图中文字

把准确文案放在双引号中，说明位置、层级和不得改写。长文案优先压缩信息或拆分版面，不把大段文字硬塞进单张图。

## 避免

- 重复堆叠质量词；
- 模糊代词，如“把它换掉”；
- 同时要求“完全保持不变”和“彻底重设计”同一对象；
- 编造未确认的版本参数或开关。
