# Seedance 2.0 Adapter

用于 Seedance 2.0 的文生视频、图生视频、参考视频生视频、多模态参考、视频编辑与延长。

## 模型特点

Seedance 2.0 可综合文本、图片、视频和音频素材，并分别参考主体、场景、构图、动作、运镜、节奏、特效、声音和叙事。它适合自然语言导演指令，也能处理多镜头与音画同步。

平台能力可能随入口变化。只有在相关界面确实支持时，才使用多素材、编辑、延长、音频或参数功能。

## 素材角色

使用平台可识别的素材引用方式；若具体界面语法未知，输出清晰的中文编号：

```text
图 1：锁定主角外观与服装。
图 2：参考场景空间与色彩。
视频 1：只参考动作顺序和速度，不参考人物与背景。
视频 2：只参考运镜和剪辑节奏。
音频 1：参考音乐节拍与情绪，不复制人声内容。
```

随后写清组合后的新内容。不要让两段视频同时控制同一段互相冲突的动作或运镜。

## 文生视频结构

简单单镜头：

```text
<时长 / 画幅 / 类型>。<主体与初始状态>。<动作过程与结束状态>。<环境物理反馈>。<机位与运镜>。<光线与风格>。<声音>。<连续性与禁止项>。
```

多镜头：

```text
整体：<用途、时长、画幅、风格、连续性>
0–Xs：<景别、主体、动作、运镜、声音>
X–Ys：<景别、主体、动作、运镜、转场、声音>
Y–Zs：<结尾动作、收束画面、声音落点>
约束：<身份、产品、空间和叙事不可漂移项>
```

总时长必须等于各段时长之和。短视频优先少而完整的镜头，不把十几个事件压进数秒。

## 图生视频

参考图已经定义了外观和空间，不要重新描述成另一幅画。补充：

- 第一帧从参考图自然开始；
- 主体如何启动动作；
- 动作分阶段发生什么；
- 衣物、头发、液体、烟尘、阴影等如何响应；
- 相机是固定、跟拍、推进、环绕还是手持；
- 最后一帧停在哪里。

若要求锁定人物或产品，明确外观、比例、服装 / 包装、Logo 与文字不变。

## 参考视频生视频

先拆出参考视频的可迁移层：

1. **表演层**：动作顺序、速度、力度、视线、互动；
2. **摄影层**：景别、机位、轨迹、对焦、镜头切换；
3. **节奏层**：事件与剪辑落点、加速 / 慢动作；
4. **声音层**：环境音、动作音、台词、音乐节拍；
5. **视觉层**：主体、场景、色彩、光线、材质。

只迁移用户指定的层。主体替换任务应写“以图 1 主体替换视频 1 主体，保留视频 1 的动作、镜头和节奏”，并补充比例、接触、遮挡和光影融合。

## 视频编辑

定位到明确片段或事件：

```text
仅修改视频 1 中 <时间段 / 动作事件>：<目标变化>。保持前后镜头、角色身份、动作连续性、运镜、节奏与原音频不变。修改后的动作从前一状态自然衔接，并在后一状态前完成。
```

## 视频延长

从原视频最后可见状态继续，不重复开头：

- 说明谁处于什么位置和动作状态；
- 接下来发生的动作；
- 相机如何接续原轨迹；
- 场景、光线、天气和声音如何连续；
- 延长段在哪里结束。

## 动作与运镜

- 主体动作和相机运动分开写。
- 一个镜头优先一个主要相机意图。
- 写可观察动作，不用“震撼、炸裂、有张力”代替行为。
- 高速动作写启动、接触、反作用与收势，保证因果和物理反馈。
- 慢动作只用于明确瞬间，并说明何时恢复正常速度。

## 声音

按需写：

- 环境底噪；
- 动作拟音及同步点；
- 台词、说话者、语气与出现时刻；
- 音乐风格、节拍与起伏；
- 无音乐 / 无对白 / 仅自然声音。

台词逐字引用，不让旁白、角色对白和字幕互相混淆。

## 常见风险

- 多主体外观漂移：减少同屏复杂互动，重复核心身份锚点。
- 动作断裂：减少事件数量，补全起点、过程和终点。
- 运镜混乱：删除互相冲突的推进、拉远、环绕和摇移。
- 文字不稳：只保留必要短文案，并在 Prompt 中逐字锁定。
- 音频失真：降低同时发生的对白、音乐和复杂拟音数量。
