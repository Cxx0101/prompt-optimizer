# Ideogram Adapter

Use when the image is typography-heavy, poster-like, logo-like, packaging-oriented, or explicitly targeted at Ideogram.

## Prompt priorities

1. Purpose and format.
2. Exact text.
3. Typography hierarchy.
4. Layout and placement.
5. Visual motif/subject.
6. Color system.
7. Style/medium.
8. Production constraints.

## Exact text

Quote every required string. Never rewrite the user's copy unless asked.

Specify relationships such as:

- headline centered at top, about three times the visual size of the subtitle;
- small date line aligned bottom-right;
- no additional words anywhere else.

## Typography

Use broad categories that map to visible design decisions:

- serif / sans-serif / grotesk / humanist sans / condensed / monospaced / script / display;
- light / regular / semibold / bold / black;
- uppercase / title case / lowercase;
- tight or generous tracking.

## Graphic design

State grid, alignment, negative space, margins, border treatment, illustration/photo relationship, and print/screen intent when useful.

## Output form

Return one design-oriented prompt. Keep the exact copy visually easy to identify.
