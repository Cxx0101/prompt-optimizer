# Workflow: Posters, Covers, Typography, and Graphic Design

## Copy lock

Treat user-provided copy as immutable unless asked to edit it.

Create a copy map:

- primary headline;
- secondary line/subhead;
- date/location/price/CTA;
- optional small print.

## Layout lock

Specify:

- orientation/aspect ratio;
- safe margins;
- alignment system;
- headline location;
- image/illustration location;
- negative space;
- visual reading order.

## Type direction

Use visible characteristics:

- serif vs sans;
- condensed vs wide;
- high-contrast editorial serif;
- neutral grotesk;
- geometric sans;
- hand-painted display;
- monospaced technical;
- uppercase/lowercase;
- tight/wide tracking.

## Prompt strategy

Put exact visible text early enough to be treated as a hard requirement. Quote it. State "no additional text" when appropriate.

## Dense copy

If the user requests a large paragraph of exact text, warn only when necessary and suggest splitting into multiple assets or adding body copy in post-production. Do not silently truncate it.
