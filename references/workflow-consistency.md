# Workflow: Character and Product Consistency

## Build an invariant identity block

Keep it short enough to repeat exactly.

### Character identity

Include only stable markers:

- approximate age range;
- facial structure and distinctive features;
- eye/hair characteristics;
- skin tone where relevant;
- signature accessory, scar, hairstyle, or wardrobe component when essential.

Do not overload with transient expression, pose, weather, or scene details.

### Product identity

Include:

- silhouette and proportions;
- material and finish;
- key geometry;
- controls/openings/edges;
- logo/label position if supplied;
- signature color/markings.

## Separate invariants from variables

Invariant: identity/product block.

Variable: pose, action, location, time, lighting, camera, outfit when allowed, mood.

## Reference-driven consistency

If a reference image exists, explicitly ask to preserve identity/geometry and state which properties may change.

## Sequence continuity

Across multiple prompts:

- repeat the invariant block verbatim;
- reuse wardrobe/product state unless a story beat changes it;
- keep orientation details consistent when continuity matters;
- avoid changing eye color, hairstyle, product proportions, logo placement, or distinctive marks accidentally.
